## 🏗️ ¿Qué es SIGRES?

Solución multiplataforma (web + móvil) para **digitalizar y centralizar** los procesos de restaurantes:
- 🧾 Pedidos en tiempo real (mesero → cocina → caja)
- 📦 Inventario con alertas de stock mínimo
- 💳 Facturación automatizada
- 🪑 Gestión de mesas
- 📊 Reportes de ventas
- 📱 Menú digital por código QR (sin login para el cliente)
